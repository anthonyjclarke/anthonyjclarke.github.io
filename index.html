CYD Web Installers

Firmware for the ESP32 Cheap Yellow Display, installed over USB straight from this page. Pick a project and your board, connect it with a USB data cable, and click install. You don't need PlatformIO or any other tools.

What to expect

  • First install: say yes when asked to erase the device.
  • Already running that firmware? The installer recognises it and offers Update. Your settings and WiFi are kept.
  • WiFi: after installing, choose Configure WiFi in the installer if it's offered, or use the project's own setup steps.
  • Wrong board? A blank or garbled screen won't harm anything. Install again with the right board selected.

Requirements

  • Desktop Chrome, Edge or Opera. Firefox and Safari can't talk to USB serial ports.
  • On Windows, if no port appears, install the CP210x or CH340 driver, depending on your board's USB chip.
  • Some USB cables only carry power. If no port appears, try another cable.
